# Sats Brew website

Static site for [satsbrew.com](https://satsbrew.com). Plain HTML + `styles.css`, no build step. Served by GitHub Pages from `main` (root).

Placeholders are in square brackets (e.g. `[Beer name]`) and styled in muted italics. Search for `placeholder` / `[` to find them.

Local preview: `python3 -m http.server 8000`
